# 勉強仲間：通報を受けたときの手順

通報はアプリから CloudKit の公開データベース（`BuddyReport`）に届きます。開発者だけが読めるように、セキュリティロールを docs/buddies-setup.md の 4 のとおりにしておくこと。

## 見る

1. https://icloud.developer.apple.com/dashboard → `iCloud.com.ni.StudyTimerAndVideo` → **Production** → Records
2. Database: Public、Type: `BuddyReport`、新しい順
3. 1件に入っているもの

| フィールド | 中身 |
| --- | --- |
| `reporter` | 通報した人の利用者番号 |
| `target` | 通報された人の利用者番号（CloudKit がアプリごとに振る番号。Apple ID は分からない） |
| `targetNickname` / `targetCode` | 名前と4桁の番号（4桁は人と重なることがある） |
| `groupName` / `groupZone` | グループ |
| `reason` | `name`（名前）/ `photo`（写真）/ `harassment`（いやがらせ）/ `other` |
| `note` | 通報した人が書いたこと |
| `photo` / `photoCreatedAt` | 写真の通報のとき、その写真 |

少なくとも週に1回は見る。写真の通報は、届いてから24時間以内に判断する。

## 判断と対応

| 内容 | 対応 |
| --- | --- |
| 名前・グループ名がよくない | NG ワードの一覧（`BuddyWordFilter`）に足して次の版で弾く。悪質なら写真の締め出しも |
| 写真がよくない（性的・暴力的・他人が写っている など） | **写真の機能から締め出す**（下）。通報した人にはアプリ上で何も返さない |
| いやがらせ | 状況を見て締め出す。グループから外すのはオーナーにしかできないので、ブロックとオーナーへの相談をすすめる（問い合わせが来たとき） |
| 当てはまらない | 何もしない |

### 写真の機能から締め出す

Records → Public → `BuddyPhotoBan` → New Record

- Record Name：`ban-<target の値>`（例：`ban-_a1b2c3…`）
- フィールド `note`：理由と日付（例：`2026-11-02 photo report`）

置くと、その人は写真を出せなくなり、その人の写真はだれの画面にも出なくなります（次に読み込んだとき）。解くときはレコードを消す。

## 重い内容

- **児童の性的な画像、命に関わる内容**：通報レコードは消さずに残し、すぐに締め出す。警察（各都道府県警のサイバー犯罪相談窓口）に相談し、インターネット・ホットラインセンターにも通報する
- 警察から照会があったときは、開発者が持っているもの（利用者番号、名前と4桁の番号、通報の写真、日時）を渡す。その人が誰かは Apple への照会で分かる
- 対応した日と内容を、このリポジトリの外（個人のメモなど）に記録しておく

## 消す

- 対応が終わった通報は、90日を目安に消す（重い内容は警察との話が終わるまで残す）
- プライバシーポリシーに「通報で受け取った写真と番号は、確認と対応のために保存し、対応後に消す」と書いてある

## これから作る機能への反応を数える

「保護者に共有（準備中）」の案内で押された答えは、公開データベースの `BuddyInterest` に1人1件で残る（名前は入らない）。

- Records → Public → `BuddyInterest`、`feature` が `parent` のもの
- `answer`：`yes`（使ってみたい）/ `no`（いまはいい）、`source`：`settings` / `buddies`（どこで押したか）
- 判断の目安：表示した人のうち `yes` が 1 割を超えるなら作る（表示した人の数はまだ測れないので、ダウンロード数と比べる）
