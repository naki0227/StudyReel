# Pro にお金を払う価値があるかを確かめる

2026-10-24 時点では**確かめられていない**。購読者はまだいない（docs/app-store-connect-pro.md）。
このページは「何を見れば分かるか」「数字を見て何を決めるか」「Pro を厚くした内容」をまとめる。

## 見る数字

`.github/workflows/pro-report.yml`（毎週月曜 9:17、手動でも動かせる）が、App Store Connect の売上レポートから週ごとに出す。

| 数字 | 意味 |
| --- | --- |
| ダウンロード | 初めて入れた数（再ダウンロード・アップデートは数えない） |
| お試し開始 | 1週間の無料お試しを始めた数 |
| お試し→有料 | お試しのあと、そのまま払った数 |
| 最初から有料 | お試しを使わずに買った数 |
| 解約・更新 | 自動更新を止めた数・更新された数 |
| 有料・お試し中の人数 | 最後の日の時点 |

**準備（1回だけ）**：App Store Connect →「支払いと財務レポート」の左上にある番号（ベンダー番号）を、GitHub の Secrets に `ASC_VENDOR_NUMBER` として入れる。
Slack にも送るときは、Slack の Incoming Webhook の URL を `SLACK_WEBHOOK_URL` に入れる。

App Store Connect の画面（App Analytics →「サブスクリプション」）でも同じ数字が見られる。こちらはペイウォールを見た数は分からない。

## 目安と、決めること

ダウンロードが週 30 件より少ないうちは、割合がぶれるので4週ぶんまとめて見る。目安は教育・生産性アプリでよく言われる値で、StudyReel の実績ではない。

| 見るところ | 目安 | 下回ったら |
| --- | --- | --- |
| お試し開始 ÷ ダウンロード | 5% | Pro があることが伝わっていない。ペイウォールを出す場面（録画の保存後、統計の教科別、勉強仲間の2つ目、保護者の Pro 欄）を見直す |
| お試し→有料 | 30% | お試しの1週間で価値が伝わっていない。お試し中に Pro の機能を1回使ってもらう導線（教科別の内訳、ロゴなし保存）を足す |
| 解約 ÷ 有料 | 月 10% | 続けて払う理由が弱い。毎週・毎月見返す機能（週のふりかえり、保護者の推移）を厚くする |

8週ぶん数字がたまったら、このページに結果を書き足して、価格（月 ¥600・年 ¥4,800）と Pro の中身を見直す。

## 1.9 で Pro に足したもの

いままでの Pro は「動画の見た目」（ロゴなし、フォント、BGM、テーマ）が中心で、受験生本人には「なくても困らない」ものが多かった。
お金を出す人を、本人だけでなく**保護者**にも広げる。

- **保護者：教科ごとの時間・4週間の推移**（見守りのカード。保護者の端末が Pro のとき）
  - 4週間の推移は、子が見せている間はいつも届く。教科ごとの時間は、子が「教科ごとの時間も見せる」をオンにしたときだけ
  - 塾の先生には Pro なしで出す（塾は別に契約する）
- **ファミリー共有**：保護者が Pro を買うと、子も Pro を使える（最大6人）。ペイウォールに「ファミリー共有で、家族も Pro を使えます」と出る
  - `appstore/release.yml` の `family_sharing: true` で、マージしたときに月額・年額の両方をオンにする
  - **一度オンにすると開発者は戻せない**（Apple の決まり）。家族と分けるかどうかは、買った人が iPhone の設定 → Apple アカウント → サブスクリプションで選べる
- 「保護者・塾に共有」そのもの（今日・今週・連続日数）は無料のまま。まず使ってもらい、もっと見たい保護者に Pro を案内する

## 次に厚くする候補（数字を見て選ぶ）

| 候補 | 効きそうな数字 |
| --- | --- |
| 月のふりかえり（1か月の時間・教科・連続日数を1枚のカードと動画に） | 解約 |
| 目標（D-day）までの見込み（このペースで何時間になるか） | お試し→有料 |
| 保護者への週のレポート（日曜の夜に、教科と推移を1枚で） | 保護者の購入 |
| 勉強仲間のグループの週のランキング履歴 | お試し開始 |
