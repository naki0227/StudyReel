# 売上を伸ばす手順（2026-11 から）

売上 ≒ ダウンロード × お試しを始める割合 × 有料になる割合 × 値段。今は最初のダウンロードが少ないので、まず人を増やしつつ、1人あたりの金額が大きい塾と保護者を取りに行く。根拠は docs/research/market.md。

## 1. 塾・教室に売る（1件 月 3,000〜8,000円）

- ページ：https://enludus.com/products/studyreel-school（company-web の PR #42。料金が決まったら公開）
- 資料：https://enludus.com/products/studyreel-school-guide.pdf（A4 2ページ。印刷して持っていく・メールに付ける）
- 申し込みはメール（contact@enludus.com）。届いたら：
  1. CloudKit Console（Production・公開 DB）で `BuddySchoolCode` を作る：レコード名 `school-<コード>`（英小文字と数字で12文字以上、推測されないもの）、`schoolName`、`maxStudents`（お試し・ベーシック 30、スタンダード 100）、`expiresAt`（お試しは1か月後）。手順は docs/family-and-school.md
  2. 塾コードと、先生向けの始め方（資料の「始め方」）をメールで返す
  3. お試しが終わる1週間前に、続けるかを聞く。続けるなら請求書を送り、`expiresAt` を延ばす
- アプリの外（請求書）で売るのは、塾という団体に売る場合に当たる（App Store 審査ガイドライン 3.1.3(c)）。個人の利用者に塾コードを売らない
- 最初の1件は、知り合いや近所の個別指導塾にお試しを頼む。使ってもらった声をページに載せる

### 塾へのメール

- 送ってよいのは、公式サイトに問い合わせ用として載っているアドレスだけ。「営業・広告のメールお断り」の塾には送らない（特定電子メール法）
- 必ず入れる：Enludus の名前・住所・contact@enludus.com・「不要な場合はご返信ください」の一文。断られたら二度と送らない
- 1件ずつ、塾の名前とその塾に合わせた一言を入れて送る。1日10件くらいまで
- 送った塾の一覧（名前・アドレス）はリポジトリに入れない

## 2. 保護者に払ってもらう

- 1.10：見守りの画面で「ファミリー共有で、お子さんも同じ Pro を使えます」、Pro の画面にも保護者向けの一言
- ファミリー共有は App Store Connect でオン（1.9 の提出で反映済み）

## 3. Pro を見せる時機（1.10）

- 初めて動画つきの記録を保存してホームに戻ったとき、その回だけレビューの代わりに Pro の画面を出す（`FirstVideoOffer`）
- 4週間後に、お試しを始めた数を pro-report の数字で前と比べる

## 4. お試しの期間を2週間に（App Store Connect で手で変える）

調べた数字では、お試しが長いほうが有料になる割合が高い（17日以上で 42.5%、短いと 25.5%。RevenueCat）。

1. App Store Connect → StudyReel → サブスクリプション → StudyReel Pro（月額）→「サブスクリプション価格」の下の「お試しオファー」
2. 今の「1週間 無料」を終わらせ（終了日を今日に）、新しく「2週間 無料」をすべての国で作る
3. 年額も同じにする
4. アプリの Pro の画面は、オファーの長さを App Store から読んで「最初の2週間は無料」と出す（コードの変更は要らない）
5. 変えた日を docs/pro-value.md に書き、4週間後に有料になる割合を比べる

## 5. 勉強垢の人に Pro を配る

1. App Store Connect → サブスクリプション → 年額 →「オファーコード」→ 新しいオファー：「3か月無料」、新規の人だけ、コードは「一度だけ使えるコード」を 20 個
2. フォロワー 1,000〜10,000 人くらいの勉強垢（Instagram・TikTok・X）を 20 人選ぶ。顔を出していない人を優先（モザイクがいちばん効く相手）
3. DM の文面（例）：

```
はじめまして、StudyReel というタイムラプスの勉強記録アプリを作っている Enludus です。
いつも投稿を拝見しています。

StudyReel は、勉強しているところを撮ると、顔を自動でモザイクにしてくれるアプリです。
よろしければ、有料版（Pro）を3か月無料で使っていただけるコードをお送りします。
投稿していただく約束は要りません。使ってみての感想をいただけたらうれしいです。
もし投稿してくださる場合は、無料でお渡ししたものなので「#PR」などを付けていただけると助かります。

App Store：https://apps.apple.com/jp/app/id6756177589
```

4. 送った相手・コード・使ったか・投稿があったかを表にしておく（個人の名前はリポジトリに書かない）
5. 18歳未満と分かる人には送らない（勉強垢は中高生が多い）。大学生・社会人の資格勉強の人を優先する
6. 無料で渡したものを投稿してもらうときは、広告と分かる書き方（#PR など）をお願いする（景品表示法のステルスマーケティング規制、2023年10月から）

## 6. App Store のイベント（In-App Events）

試験の時期に合わせて出すと、検索やおすすめに出やすくなる。App Store Connect → アプリ →「App 内イベント」で作る。カードの画像は 1920×1080 と 1080×1920（`tools/remotion` で作れる）。

| 時期 | 名前（30文字まで） | 短い説明（50文字まで） |
| --- | --- | --- |
| 12月〜1月（共通テスト前） | 共通テストまで、毎日タイムラプス | 顔はモザイクで。毎日の勉強を撮って、1年の草を埋めよう |
| 1月〜2月（期末・資格） | 25分集中チャレンジ | 25分＋5分休憩を1日4回。休憩中は撮影も止まります |
| 4月（新学期） | 新学期、記録をはじめよう | 今日から1年の草をつけよう。勉強した日が色で埋まります |
| 7月〜8月（夏休み） | 夏休みの勉強を1本の Vlog に | 毎日撮って、1か月分を60秒の Vlog にまとめよう |

## 7. 自分で勉強垢を作る

- 週1回、1年の草のカードや休憩の画面を載せる
