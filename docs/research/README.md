# 調べたこと（2026-10-25）と、作る順番

- science.md … 勉強の続け方・休憩・連続記録・音・見られること・保護者の見守りについての論文と調査
- market.md … 競合のレビュー（不満と要望）、勉強垢・Study with me の文化（日本・韓国・台湾・中国）、課金と伸ばし方
- ios.md … 機能ごとに、このコードでどう作るか・どのファイルが変わるか・審査の心配

## 3つを合わせてわかったこと

1. **一番の不満は「長い録画が消える・固まる」**（market）。StudyReel も、書き込みに失敗すると録画を消してしまう（ios：TimeLapseRecorder の finish → discardWriter）。発熱・電池・空き容量も見ていない。**機能より先にここ**
2. **顔のモザイクは本当に求められている**（FocusLapse のレビューに要望）。ストアの1枚目にした
3. **カメラなしの記録も、仲間の合計・草に同じく数える**（market：学校でスマホが使えない人の要望。science：記録すること自体が効く d=0.40）
4. **連続日数は「途切れた」を責めない**。今年何日やったかを主役に、休み（フリーズ）と「おかえり」（science：Silverman 2023、Milkman 2021）
5. **ポモドーロは 25/5 を既定に、50/10・90/15 と、時間に合わせて休憩を勧める型**。休憩中はスマホから離れるよう勧める（science：Biwer 2023、Kang 2019）。休憩中は録画を止める仕組みはもうある（ios）
6. **音は歌なし・控えめ・既定オフ**。雨・ブラウンノイズはもうある。足すのはホワイトノイズと音量（science：Vasilev 2018）
7. **仲間に順位を見せすぎない**（science：上との比較は自信を下げる）。10秒の動画は審査の心配が一番大きいので最後
8. 宣伝に「撮ると集中できる」「66日で習慣」「○%アップ」は使わない（根拠が弱い）

## 作る順番

1. 録画を守る：書き込みに失敗しても撮れた分を残す・発熱で画質を下げてから止める・空き容量を見る・カメラを 30fps から下げて電池を減らす
2. カメラなしの記録（カメラを起こさない）
3. 1年の草（今年何日）と共有カード・休み（フリーズ）と「おかえり」
4. ポモドーロ（日時で数える・休憩の通知・ライブアクティビティ）
5. iPhone から始める（ショートカット・Siri「StudyReelで勉強を始める」・コントロールセンター・アクションボタン）
6. 音：ホワイトノイズ・音量・電話のあとに戻す
7. 1か月の Vlog
8. 仲間に10秒のモザイク動画（モザイクなしは型で送れないようにする）
